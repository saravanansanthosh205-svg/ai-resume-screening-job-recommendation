ABOUT PROJECT

AI Resume Screening System

The AI-Based Resume Screening and Job Recommendation System is a web-based application designed to analyze resumes automatically using Natural Language Processing techniques.

The system extracts important skills from the resume and compares the resume content with predefined job profiles using TF-IDF and cosine similarity.

Based on the analysis, the system calculates a final compatibility score and displays suitable job roles for the candidate.
